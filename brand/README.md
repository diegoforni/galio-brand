# Galio brand exploration

Three pre-launch brand identity directions are provided for decision-making, not as three identities to use simultaneously.

## Deliverables

- `concepts/index.html` — visual comparison and recommendation
- `concepts/01-quiet-defiance/guide.html` — Option 1: **Galio / Quiet Defiance**
- `concepts/02-continuous-signal/guide.html` — Option 2: **Galio Security / Continuous Signal**
- `concepts/03-assured-horizon/guide.html` — Option 3: **Galio CyberSecurity / Assured Horizon**
- `concepts/04-liquid-standard/guide.html` — Option 4: **Galio / Liquid Standard**, inspired by elemental gallium
- `concepts/04-gallium-variations/index.html` — focused refinement of the gallium route: **Phase 29.76**, **Float**, and **Skin**
- `concepts/05-full-brand-variations/index.html` — presentation board for the gallium-derived systems
- `concepts/05-full-brand-variations/Galio-Full-Brand-Systems.pdf` — eight-page presentation-ready export of the three systems
- `concepts/05-full-brand-variations/living-metal/guide.html` — standalone **Cool Living Metal** guide
- `concepts/05-full-brand-variations/living-metal/Galio-Living-Metal-Cool-Guide.pdf` — standalone Cool Living Metal PDF
- `concepts/05-full-brand-variations/living-metal/guide-warm.html` — standalone **Warm Living Metal** guide
- `concepts/05-full-brand-variations/living-metal/Galio-Living-Metal-Warm-Guide.pdf` — standalone Warm Living Metal PDF
- `concepts/05-full-brand-variations/systems.md` — strategy and design rules for all four separate versions
- Each concept includes editable SVG logo assets and a print-ready PDF.
- `identity.md` — designer-facing identity brief and rationale
- `guidelines.md` — shared brand essentials and decision guidance

## Recommendation

Advance either **Cool Living Metal** or **Warm Living Metal** as the distinctive lead and test them as separate identities with buyers. Both use Sora, Manrope, and IBM Plex Mono, but their palettes, art, and applications must never be mixed. Keep **Civic Alloy** as the purpose-led challenger.

All three active systems include **Galio Open**, the proposed program for free pentesting for selected nonprofits. It uses the same experts, depth, and remediation standard as paid work.

Before public launch, conduct trademark, company-name, and domain checks in every intended market. The concepts are original creative directions, not legal clearance.
